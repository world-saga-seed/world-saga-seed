# Method: the ideas behind the kit

The pipeline says what to do. These pages say why, so you can bend a step without breaking what it was for. The first page is the project scaffolding, plain task management; the rest are the fiction method built on it. Read them once, in order.

| Page | The idea |
|---|---|

| [Why plan/ (wiki)](https://github.com/world-saga-seed/world-saga-seed/wiki/Why-plan) | A model forgets. A folder of plain files does not. The plan is how a long book keeps its memory between sessions. |
| [Oracles for prose (wiki)](https://github.com/world-saga-seed/world-saga-seed/wiki/Oracles-for-prose) | Prose has no test suite. Narrow critics, forced to quote, checked against planted faults, are the nearest thing. |
| [reader-tests](../../plan/workflows/reader-tests.md) | The one test of prose with an answer key: a spec per chapter, and blind readers scored against it. |

| [cards.md](cards.md) | One fact, one home. A card holds one clean version of one thing. |

## The one-sentence version

Write every decision down once, mark everything that is not yours, check every claim against the text, and let only the writer say "done".
